Como executar

1- Baixe os arquivos deste repositório para o seu computador.
2- Abra o arquivo do notebook Python (.ipynb) no VS Code ou no Google Colab.
3- Certifique-se de que as bibliotecas Pandas e Matplotlib estão instaladas.
4- Mantenha o arquivo Base Varejo.csv na mesma pasta do notebook, caso o código esteja configurado para carregar o arquivo localmente.
5- Execute as células do notebook na ordem apresentada, do início ao fim.
