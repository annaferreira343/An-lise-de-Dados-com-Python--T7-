 Mini-Projeto Avalistibvo — Análise de Dados de Varejo

Sobre o projeto: ele tem como objetivo realizar uma análise exploratória de uma base de dados de varejo utilizando Python e a biblioteca Pandas. 
O trabalho faz parte do mini-projeto avaliativo do curso de Análise de Dados e busca aplicar conceitos de análise e limpeza de dados, estatística descritiva e visualização de informações.

Base de dados: O projeto utiliza o arquivo "Base Varejo.csv", que contém informações sobre compras, clientes, produtos e características dos consumidores.

Etapas do projeto:
- Carregamento e inspeção da base de dados.
- Verificação de valores ausentes e registros duplicados.
- Limpeza e organização dos dados.
- Análise exploratória das informações.
- Agrupamentos e cálculos estatísticos.
- Criação de gráficos e interpretação dos resultados.

Ferramentas utilizadas
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Como executar
1. Baixe os arquivos do repositório.
2. Abra o notebook Python no VS Code ou Google Colab.
3. Verifique se as bibliotecas necessárias estão instaladas.
4. Execute as células na ordem apresentada.
